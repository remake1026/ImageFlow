# ImageFlow 功能说明

ImageFlow 用于在不修改原始照片的前提下，完成多尺寸裁剪、水印、命名与批量导出。

## 裁剪与预览

- 支持原图比例、1:1、4:5、3:4、9:16、16:9 和自定义尺寸。
- 每张照片、每个尺寸分别保存缩放与构图位置；可拖动裁剪框、滚轮缩放、方向键微调，并可显示三分法辅助线。
- 在画布中央的裁剪框内双击，显示当前裁剪后的成图预览（包含已启用的水印）；再次双击返回默认构图编辑，可循环切换。
- 在画布中，Alt + 鼠标滚轮以鼠标位置为中心缩放，空格 + 鼠标左键拖动可平移查看细节；点击“适合窗口”重置预览视图，不改变裁剪或导出结果。
- 放大或查看裁剪局部时，按屏幕实际像素需求从源文件后台加载高清图；滚动和拖动期间使用轻量预览，停下约 180 毫秒后请求清晰画面，加载时间取决于图片大小和磁盘速度。
- 高清缓存只保留当前照片一张，32 位像素占用上限约 128 MiB，超大照片会按上限缩小；解码时可能临时使用额外内存。快速切图会丢弃过期结果，并只继续加载最后选中的照片。缩略图列表、裁剪参数及原图导出不受影响。
- 点击顶部“恢复默认构图预览”，返回带裁剪框的编辑视图；此操作不重置或修改构图参数。
- 底部尺寸缩略图会完整显示图片和选中边框，横向滚动条不会遮住图片；预览在停止拖动后更新，避免水印合成影响拖动流畅度。
- 拖动底部横向滚动条后切换照片，会保留当前滚动位置，不再自动跳回最前面。

## 水印

- 支持透明 PNG 或 WebP 水印，能保存和复用水印预设。
- 已选择水印预设时，下拉框只显示预设名称，不再重复显示其中的 PNG 文件名。
- 启动恢复任务时会立即按活动预设校准水印位置和参数，无需来回切换预设。
- 可设置水印位置、大小、透明度、旋转、边距、偏移和安全区。
- 可将当前水印设置应用到同一照片的全部输出尺寸；预览与导出使用相同的水印定位规则。

## 图片与项目管理

- 右侧设置使用尺寸、裁剪、水印、命名、导出五个水平标签页；切换时保留配置和各页滚动位置。顶部标签与底部导出按钮固定，仅当前页内容内部滚动。
- 可批量导入 JPG、PNG、WebP、TIFF、BMP 等常用格式。
- 支持保存与打开项目，保留照片路径、尺寸模板、构图、水印和导出设置。
- 启动时先显示主界面，再在后台恢复上次任务的照片缩略图；预览会按源文件版本持久缓存，后续启动无需重新解码全部大图。
- 支持撤销、上一张/下一张切换，以及按尺寸浏览全部照片的缩略图。
- 顶部采用单排深色自定义标题栏，Logo、ImageFlow、“管理后台”和最小化/最大化/关闭按钮位于同一排，不再出现额外的白色原生标题栏；支持拖动窗口、双击标题栏最大化或还原，并保留窗口边缘缩放。
- “管理后台”排列在 ImageFlow 后，可查看并清除本机预览缓存。
- 管理后台支持新增、删除 SKU，并可在新增时填写可选颜色；双击 SKU 或颜色单元格可直接编辑，点击空白处自动保存，主界面的命名下拉框会立即更新。

## 命名与导出

- 文件名可组合品牌、SKU、颜色、日期、序号等字段，也可保留原文件名。
- 支持 JPG、PNG、WebP 导出，含质量设置、ICC/EXIF 选项、按尺寸建立子文件夹及同名保护。
- 一键批量导出所有已选尺寸；原始照片始终不会被改名、覆盖或修改。
