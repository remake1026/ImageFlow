# ImageFlow 1.4.0 详细更新说明

ImageFlow 1.4.0 为 Windows 安装版加入按文件增量更新，后续升级只下载发生变化或缺失的程序文件。无法使用增量更新时，自动使用完整安装包。

[前往 v1.4.0 发布页](https://github.com/remake1026/ImageFlow/releases/tag/v1.4.0)

## 增量更新与失败恢复

- 下载前校验本地文件，通过 HTTP Range 读取变化文件的压缩数据，不重复下载未变化的运行库。
- 每个文件解压后校验 SHA-256，安装前再次检查本地文件与暂存文件。
- 清单不兼容、分段下载不受支持或文件校验失败等情况下，自动回退到完整安装包。
- 应用增量更新时先备份；替换失败先回滚，再自动运行完整安装包。保留安装位置、快捷方式及用户数据。
- 下载进度显示变化文件数量及总下载量，并提高进度刷新频率。

## 首次升级

1.3.x 的旧更新器仍会下载完整安装包。先安装一次 1.4.0，之后更新才能使用增量功能。

## 安装包与更新附件

Windows 用户下载 [ImageFlow 1.4.0 通用安装包](https://github.com/remake1026/ImageFlow/releases/download/v1.4.0/ImageFlow-1.4.0-Windows-x86-x64-Setup.exe) 安装。

发布页中的 `manifest.json` 和 `files.bin` 是软件自动更新使用的附件，无需手动打开。

发布页另提供 [macOS Apple 芯片安装包](https://github.com/remake1026/ImageFlow/releases/download/v1.4.0/ImageFlow-1.4.0-macOS-arm64.dmg) 及其 [SHA-256 校验文件](https://github.com/remake1026/ImageFlow/releases/download/v1.4.0/ImageFlow-1.4.0-macOS-arm64.dmg.sha256)。上面的增量更新说明适用于 Windows 安装版。

## Windows 兼容性

支持 Windows 10 1809 及以上和 Windows 11，自动匹配 x86/x64。ARM64 兼容分支尚未实机验证。Windows 安装包未进行 Authenticode 签名。
