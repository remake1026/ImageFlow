# NuPhy 图片交付助手（MVP）

一个 Windows 本地桌面工具，用于将修图成片批量裁剪为多个尺寸、添加 PNG 水印、按规则命名并导出。所有构图和水印调整均为无损参数，原图不会被修改或覆盖。

## 已完成的 MVP 功能

- 导入多张 JPG、PNG、WebP、TIFF、BMP 图片，支持中文及空格路径。
- 内置原图比例、1:1、4:5、3:4、9:16、16:9 尺寸，可增删改自定义尺寸。
- 每张图片、每个尺寸独立保存裁剪缩放和构图位置。
- 固定裁剪框：拖动画面、鼠标滚轮缩放、方向键细调、Shift + 方向键大步调整、双击恢复自动适配。
- 三分法辅助线、上下左右按钮、自动居中、主体偏上/偏下、复制构图。
- 透明 PNG 水印：九宫格定位、鼠标拖动、偏移、大小、不透明度、旋转、边距与安全区；可按尺寸独立设置。
- JPG / PNG / WebP 后台批量导出，提供进度、取消、避免同名覆盖、按尺寸建子文件夹、ICC/EXIF 保留选项。
- SKU、颜色下拉选项从 `products.csv` 导入；切换 SKU 时会恢复该 SKU 最近选择的颜色。
- 导出命名统一为“品牌 SKU 颜色 原图片名”，各部分以空格分隔。
- 保存/打开 `.nuphyproject` 项目文件；项目只记录原图路径和编辑参数。路径失效时可以重新定位。
- 保存水印/命名预设，以及记住上一次输出目录。

## 运行前准备

1. 安装 **Python 3.11（64 位）**：<https://www.python.org/downloads/release/python-3110/>。
2. 安装时务必勾选 **Add Python to PATH**。
3. 本项目不需要网页服务器。

## 启动

直接双击 [start.bat](start.bat)。第一次启动会自动安装 PySide6、Pillow 和 PyInstaller，之后会打开软件。

也可以在本目录的命令行中运行：

```bat
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py
```

## 基本使用流程

1. 点击“导入照片”，选择修图完成的成片。
2. 在右侧“尺寸设置”勾选需要交付的尺寸，点击尺寸名称切换到该版本。
3. 在中间预览区拖动图片、滚轮缩放，分别完成各尺寸构图。
4. 在“水印设置”选择透明 PNG；每个尺寸可单独移动水印、调整大小和位置。
5. 填写品牌，并在下拉框选择 SKU、颜色；文件名会自动显示为“品牌 SKU 颜色 原图片名”。
6. 点击右下角“**一键导出全部**”，确认文件名预览后导出。

默认会在输出目录创建各尺寸子目录。若禁止覆盖而遇到同名文件，软件会自动增加 `_2`、`_3` 后缀，保护已有文件。

## 打包 EXE

双击 [build.bat](build.bat)。完成后可执行文件位于：

```text
dist\NuPhy图片交付助手\NuPhy图片交付助手.exe
```

首次打包需要联网下载依赖。生成目录中的文件需保持完整，不要只复制 `.exe` 单文件。

## 项目结构

```text
main.py                 主窗口与界面交互
app/models.py           图片、尺寸、裁剪、水印和导出数据模型
app/crop_canvas.py      中央裁剪与水印交互预览控件
app/image_processor.py  EXIF 方向、裁剪、水印和最终图片渲染
app/exporter.py         后台批量导出线程
app/project_io.py       项目文件读写
app/presets.py          本地预设存储
products.csv            SKU 与颜色下拉数据源
```

## MVP 范围说明

本版本尚未提供“预设列表的下拉选择/删除界面”和“批量套用某张照片的构图到所有照片”；已保存的预设会写入本机应用配置中，后续版本可补充选择管理界面。未包含 AI 主体识别、云同步、登录、PS 插件、在线素材库和调色功能。
